# 模块代码技能（contract-code）

负责**按实施计划实施代码**——**以实施计划为主、契约为约束**，不创建/修改四件套文档（文档归 /文档）。

## 流程

### 1. 读上下文（自动发现，零路径投喂）

1. 读项目档案（目录约定、分层、组件模式）；
2. 读 `{文档根}/模块/{模块名}/` 四件套——契约 = 约束（§3 数据模型 / §4 接口概览）、接口.md 字段细节；
3. 读标杆代码（按档案标杆映射；映射缺失时 glob 找同类实现并提示回填档案）；
4. 涉及跨模块能力时读对应边界文档。

### 2. 生成实施计划（用户确认后实施）

生成 `{文档根}/计划/YYYY-MM-DD-{实施主题}.md`，必备章节：

- 需求理解
- 变更文件清单（SQL / 后端 / 前端逐个列出）
- 关键设计决策
- 验收标准
- 待确认事项
- 里程碑
- **回写清单**（实施完成后需回写的长期文档：契约变更记录 / 测试执行记录 / 接口.md 与总契约索引（由 /文档 同步维护））

向用户汇报并等待确认；一契约可对应多个实施计划（按日期+主题区分）。

### 3. 以实施计划为主实施

- SQL（进档案约定的 `sql/change/` 目录）→ 后端 → 前端；
- **契约作约束**：数据模型、API、状态机、特殊约定必须遵守；
- **偏离时先改契约（/文档 改造）再实施**，不得绕过契约直接改代码。

### 4. 一致性自检

对照检查：代码 ↔ 实施计划 ↔ 契约 §4 / 接口.md。

- 发现偏差（路径/字段/权限标识）→ 列出"待同步项"并提示 `/文档 {模块名} 同步`；
- 契约语义/权限层面变化（状态机新增状态、权限标识变更）→ 提示 `/文档 {模块名} 改造`。

### 5. 回写（交付义务，不可跳过）

按实施计划"回写清单"逐项登记：

- 契约变更记录追加一行（**事实登记**：改了哪些字段/接口/状态机）；
- 测试执行记录；
- 提示 `/文档 同步`（同步接口.md 并更新总契约索引——**索引由 /文档 维护**）。

**边界**：/代码 只做事实登记；契约语义/权限层面的修改归 /文档，提示后等确认，不得自行改契约。

## 与 /文档 的协作约定

| 场景 | 流程 |
|------|------|
| 正向开发 | `/文档 新建`（契约先行）→ `/代码`（计划 → 实施 → 回写）→ `/文档 同步`（收尾） |
| 改造 | `/文档 改造`（更新契约）→ `/代码`（新计划 → 实施 → 回写） |
| 逆向 | `/文档 补文档`（从代码提炼） |

/检查 兜底校验文档与代码一致性（含回写查账）。
